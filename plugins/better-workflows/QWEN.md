# Better Workflows bridge for Qwen Code

Run `node scripts/sbw.mjs host doctor qwen-code`, then use `route preview` or
the matching skill in `skills/`. Repository mutations require a task-owned
`TaskWorkspaceLeaseV1` worktree. Direct is valid only after
`AutoRiskAssessmentV1` selects it. Protected or remote delivery and every
release or deploy require the governed evidence route. Replay re-evaluates
evidence; it never repeats side effects.

This is the host-neutral core bridge, not the Codex-native picker, subagent,
host-trust, or plugin-cache publication experience.
