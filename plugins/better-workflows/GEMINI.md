# Better Workflows bridge for Gemini CLI

When this plugin directory is used directly, bind `<plugin-root>` to the
directory from which Gemini CLI loaded this file and verify the sibling
`gemini-extension.json`. Never resolve the helper relative to the user's
repository. Run `node "<plugin-root>/scripts/sbw.mjs" host doctor gemini-cli`,
then use `route preview` or the matching skill in `<plugin-root>/skills/`.
Repository mutations require a task-owned
`TaskWorkspaceLeaseV1` worktree. Direct is valid only after
`AutoRiskAssessmentV1` selects it. Protected or remote delivery and every
release or deploy require the governed evidence route. Replay re-evaluates
evidence; it never repeats side effects.

Shared state defaults to `XDG_STATE_HOME/better-workflows` when available and
otherwise `~/.better-workflows`; set `SBW_STATE_ROOT` for an explicit location.

This is the host-neutral core bridge, not the Codex-native picker, subagent,
host-trust, or plugin-cache publication experience.
