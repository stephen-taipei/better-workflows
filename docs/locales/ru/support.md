## Обратитесь за помощью

Если у вас вопрос по использованию или воспроизводимая ошибка\, создайте обращение на GitHub и укажите\:

- версию Better Workflows и сборку плагина Codex\;
- используемый интерфейс Codex и версию Node\.js\;
- выполненную команду или выбранный пункт меню\;
- ожидаемое и фактически наблюдаемое поведение\;
- вывод без конфиденциальных данных и минимальные шаги для воспроизведения\.

Не прикладывайте учётные данные\, необработанные личные запросы\, материалы для подписания или квитанции поставщиков услуг\.

Предложения по новым функциям должны описывать результат для пользователя\, границы безопасности и стратегию валидации\.

О предполагаемых уязвимостях необходимо сообщать по закрытой процедуре из [SECURITY\.md](security.md)\, а не через публичное обращение в поддержку\.
