## Chiedi aiuto

Per una domanda sull’uso o un difetto riproducibile\, apri una segnalazione su GitHub indicando\:

- versione di Better Workflows e versione compilata dell’estensione Codex\;
- interfaccia di Codex e versione di Node\.js\;
- comando o voce del selettore utilizzati\;
- comportamento atteso e osservato\;
- risultati di esecuzione ripuliti dai dati sensibili e un esempio minimo per riprodurre il problema\.

Non includere credenziali\, istruzioni private non ripulite dai dati sensibili\, materiale per la firma o ricevute dei fornitori\.

Le proposte di funzionalità devono descrivere il risultato per l\'utente\, il confine di sicurezza e una strategia di convalida\.

Le sospette vulnerabilità devono essere segnalate tramite la procedura privata descritta in [SECURITY\.md](security.md)\, non con una richiesta di assistenza pubblica\.
