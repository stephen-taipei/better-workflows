## រាយការណ៍ភាពងាយរងគ្រោះ

សូមប្រើ [ការរាយការណ៍ភាពងាយរងគ្រោះជាឯកជនរបស់ GitHub](https://github.com/stephen-taipei/better-workflows/security/advisories/new)។ កុំបើកបញ្ហាជាសាធារណៈសម្រាប់ភាពងាយរងគ្រោះដែលសង្ស័យ។

រួមបញ្ចូល\:

- កំណែ និងកំណែសាងសង់កម្មវិធីជំនួយដែលរងផលប៉ះពាល់\;
- បរិស្ថាន និងកំណែ Node\.js\;
- ជំហានអប្បបរមាដើម្បីបង្កើតបញ្ហាឡើងវិញ\;
- ព្រំដែនសន្តិសុខដែលរំពឹងទុក និងដែលបានសង្កេតឃើញ\;
- ផលប៉ះពាល់ និងវិធីដោះស្រាយបណ្តោះអាសន្នណាមួយដែលដឹង\;
- ថាតើរបាយការណ៍មានខ្លឹមសារសម្ងាត់ឬអត់។

កុំរួមបញ្ចូលព័ត៌មានសម្គាល់សិទ្ធិចូលប្រើដែលនៅមានសុពលភាព សោចុះហត្ថលេខា ថូខឹនរបស់អ្នកផ្តល់សេវា ខ្លឹមសារបញ្ចូលឯកជនដែលមិនទាន់កែសម្រួល សម្រាប់ម៉ូដែល ឬទិន្នន័យផ្ទាល់ខ្លួនរបស់ភាគីទីបី។

## ការឆ្លើយតប

អ្នកថែទាំគម្រោងនឹងបញ្ជាក់ការទទួលរបាយការណ៍ដែលអាចយកទៅប្រើបាន ផ្ទៀងផ្ទាត់វិសាលភាពរបស់វា និង សម្របសម្រួលការកែសម្រួលបញ្ហានិងការបង្ហាញព័ត៌មាន។ មិនមានការសន្យា SLA ដែលកំណត់ពេលឆ្លើយតបថេរទេ។ លទ្ធផលដែលមិនទាន់ដឹង ឬមិនទាន់ផ្ទៀងផ្ទាត់ឱ្យស្របគ្នា នៅតែត្រូវបានទប់ស្កាត់ ដោយបដិសេធការបន្តនៅពេលមិនទាន់បានផ្ទៀងផ្ទាត់។
