## ស្នើសុំជំនួយ

សម្រាប់សំណួរអំពីការប្រើប្រាស់ ឬកំហុសដែលអាចបង្កើតឱ្យកើតឡើងវិញបាន សូមដាក់របាយការណ៍បញ្ហានៅលើ GitHub ដោយភ្ជាប់ព័ត៌មានដូចខាងក្រោម៖

- កំណែ Better Workflows និងកំណែស្ថាបនារបស់កម្មវិធីជំនួយ Codex
- ចំណុចប្រទាក់ Codex ដែលបានប្រើ និងកំណែ Node\.js
- ពាក្យបញ្ជា ឬធាតុក្នុងម៉ឺនុយជ្រើសរើសដែលបានប្រើ
- ឥរិយាបថដែលរំពឹងទុក និងឥរិយាបថដែលបានសង្កេតឃើញ
- លទ្ធផលដែលបានដកព័ត៌មានរសើបចេញ និងឧទាហរណ៍អប្បបរមាសម្រាប់បង្កើតបញ្ហាឱ្យកើតឡើងវិញ។

កុំបញ្ចូលព័ត៌មានបញ្ជាក់សិទ្ធិចូលប្រើ អត្ថបទដើមនៃសេចក្តីណែនាំឯកជន ទិន្នន័យឬសម្ភារៈសម្រាប់ចុះហត្ថលេខា ឬបង្កាន់ដៃទទួលពីអ្នកផ្តល់សេវា។

សំណើមុខងារគួរតែរៀបរាប់អំពីលទ្ធផលរបស់អ្នកប្រើប្រាស់ ព្រំដែនសុវត្ថិភាព និងយុទ្ធសាស្ត្រផ្ទៀងផ្ទាត់។

ប្រសិនបើសង្ស័យថាមានចន្លោះប្រហោងសុវត្ថិភាព ត្រូវប្រើនីតិវិធីរាយការណ៍ជាឯកជននៅក្នុង [SECURITY\.md](security.md) មិនមែនបើកបញ្ហាស្នើសុំការគាំទ្រជាសាធារណៈទេ។
