Better Workflows ដឹកនាំដោយអ្នកថែទាំគម្រោង។

## គំរូនៃការសម្រេចចិត្ត

- អ្នកថែទាំគម្រោងទទួលយកឬបដិសេធការផ្លាស់ប្តូរការរចនា និងការចេញផ្សាយនៅកម្រិតគម្រោង។
- ភស្តុតាង តេស្តដែលអាចធ្វើឡើងវិញបាន ព្រំដែនសុវត្ថិភាព ភាពឆបគ្នា និង ថ្លៃថែទាំ ត្រូវបានពិចារណាមុនប្រជាប្រិយភាព ឬការបោះឆ្នោតតាមមតិភាគច្រើន។
- ការផ្លាស់ប្តូរកិច្ចសន្យាសាធារណៈ និងព្រំដែនសន្តិសុខត្រូវការការពិនិត្យយ៉ាងច្បាស់លាស់។
- សំណើដែលត្រូវបានបដិសេធអាចត្រូវបានពិចារណាឡើងវិញ នៅពេលភស្តុតាងថ្មីផ្លាស់ប្តូរ ការថ្លឹងថ្លែងអត្ថប្រយោជន៍និងផលប៉ះពាល់។

## អំណាចក្នុងលំហូរការងារ

នៅក្នុងការដំណើរការ Better Workflows មួយ Root គឺជាអាជ្ញាធរតែមួយគត់សម្រាប់ការផ្លាស់ប្តូរ \(mutation\) និងការទទួលយក ហានិភ័យ។ ច្បាប់ runtime នេះមិនផ្តល់កម្មសិទ្ធិលើកន្លែងផ្ទុកកូដ ឬ ជំនួសការអនុញ្ញាតរបស់ GitHub ឡើយ។

## ការចេញផ្សាយ

កំណែសាងសង់ឃ្លាំងសម្ងាត់កម្មវិធីជំនួយមិនអាចកែប្រែបាន។ កំណែបេក្ខភាពសម្រាប់ចេញផ្សាយត្រូវឆ្លងផុតច្រកត្រួតពិនិត្យដែលអនុវត្តចំពោះ តេស្ត ការវាយតម្លៃ ភាពទាន់ពេលនៃភស្តុតាង ភស្តុតាង សាខាដែលបានការពារ និងការផ្ទៀងផ្ទាត់ ប្រភព\/ឃ្លាំងសម្ងាត់ឱ្យស្របគ្នា មុនពេលផ្សព្វផ្សាយ។

## ការផ្លាស់ប្តូរអភិបាលកិច្ច

ការផ្លាស់ប្តូរអភិបាលកិច្ចត្រូវបានពិនិត្យជាការផ្លាស់ប្តូរកិច្ចសន្យាសាធារណៈ ហើយត្រូវកត់ត្រា នៅក្នុងប្រវត្តិឃ្លាំងកូដ។
