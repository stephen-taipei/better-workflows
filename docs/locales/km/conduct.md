## ស្តង់ដាររបស់យើង

យើងប្ដេជ្ញារក្សាសហគមន៍មួយដែលមានការគោរពគ្នា មានភាពម៉ត់ចត់ផ្នែកបច្ចេកទេស និងគ្មាន ការយាយី។

អាកប្បកិរិយាដែលរំពឹងទុករួមមាន៖

- ពិភាក្សាអំពីភស្តុតាង និងការថ្លឹងថ្លែងគុណសម្បត្តិនិងគុណវិបត្តិ ជំនួសឱ្យការវាយប្រហារលើបុគ្គល\;
- ផ្ដល់មតិយោបល់ជាក់លាក់ ដែលអាចយកទៅអនុវត្តបាន និងសមាមាត្រនឹងបញ្ហា\;
- ទទួលស្គាល់ភាពមិនប្រាកដប្រជា និងកែតម្រូវកំហុសដោយបើកចំហ\;
- គោរពឯកជនភាព ការរក្សាការសម្ងាត់ និងការបង្ហាញព័ត៌មានដោយមានទំនួលខុសត្រូវ\;
- ស្វាគមន៍អ្នករួមចំណែក ដោយមិនប្រកាន់ប្រវត្តិឬបទពិសោធន៍។

អាកប្បកិរិយាដែលមិនអាចទទួលយកបានរួមមាន ការយាយី ការរើសអើង ការគំរាមកំហែង ការលាតត្រដាងព័ត៌មានកំណត់អត្តសញ្ញាណបុគ្គល ការបង្ហាញចំណាប់អារម្មណ៍បែបផ្លូវភេទ ការបំភិតបំភ័យដោយចេតនា ឬការផ្សព្វផ្សាយព័ត៌មាន ឯកជនរបស់អ្នកដទៃដោយគ្មានការអនុញ្ញាត។

## វិសាលភាព

ស្តង់ដារនេះអនុវត្តចំពោះរបាយការណ៍បញ្ហា សំណើបញ្ចូលការផ្លាស់ប្ដូរ ការពិនិត្យឡើងវិញ និងការពិភាក្សាក្នុងឃ្លាំងកូដ ព្រមទាំងទីកន្លែងផ្សេងទៀតដែលមានអ្នកតំណាងឱ្យគម្រោងនេះ។

## ការរាយការណ៍ និងការអនុវត្តវិធានការ

កុំបង្ហោះរបាយការណ៍អំពីអាកប្បកិរិយាដែលមានព័ត៌មានរសើបនៅក្នុងរបាយការណ៍បញ្ហាសាធារណៈ។ ទាក់ទងអ្នកថែទាំគម្រោង តាមវិធីទំនាក់ទំនងឯកជនដែលបានផ្សព្វផ្សាយនៅលើប្រវត្តិរូប GitHub របស់ម្ចាស់ឃ្លាំងកូដ ហើយបញ្ចូល៖

- ទីកន្លែង និងកាលបរិច្ឆេទនៃហេតុការណ៍\;
- ការពិពណ៌នាផ្អែកលើការពិត\;
- តំណ ឬរូបថតអេក្រង់ដែលពាក់ព័ន្ធ\;
- កង្វល់បន្ទាន់ណាមួយអំពីសុវត្ថិភាព ឬឯកជនភាព។

អ្នកថែទាំនឹងពិនិត្យរបាយការណ៍ដោយរក្សាការសម្ងាត់ ជៀសវាងទំនាស់ផលប្រយោជន៍ ហើយអាចកែសម្រួលឬលុបមាតិកា ចេញការព្រមាន កំណត់ការចូលរួមជាបណ្ដោះអាសន្ន ឬហាមឃាត់ការចូលរួមជាអចិន្ត្រៃយ៍។ របាយការណ៍ដែលធ្វើឡើងទាំងដឹងថាមិនពិត ឬធ្វើឡើងដើម្បីសងសឹក ក៏បំពានក្រមនេះដែរ។
