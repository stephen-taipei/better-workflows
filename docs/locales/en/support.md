## Ask for help

For a usage question or reproducible defect\, open a GitHub issue with\:

- Better Workflows version and Codex plugin build\;
- Codex surface and Node\.js version\;
- command or picker entry used\;
- expected and observed behavior\;
- sanitized output and minimal reproduction\.

Do not include credentials\, raw private prompts\, signing material\, or provider receipts\.

Feature proposals should describe the user outcome\, the safety boundary\, and a validation strategy\.

Suspected vulnerabilities must use the private process in [SECURITY\.md](security.md)\, not a public support issue\.
