## Ζητήστε βοήθεια

Για ερώτηση χρήσης ή αναπαραγώγιμο σφάλμα\, ανοίξτε ένα αίτημα στο GitHub και συμπεριλάβετε\:

- την έκδοση του Better Workflows και τον αριθμό μεταγλώττισης της προσθήκης Codex·
- τη διεπαφή Codex που χρησιμοποιήθηκε και την έκδοση του Node\.js·
- την εντολή ή το στοιχείο του μενού επιλογής που χρησιμοποιήθηκε·
- την αναμενόμενη και την παρατηρούμενη συμπεριφορά·
- έξοδο χωρίς ευαίσθητα δεδομένα και τα ελάχιστα βήματα αναπαραγωγής\.

Μην περιλαμβάνετε διαπιστευτήρια\, ανεπεξέργαστες ιδιωτικές προτροπές\, υλικό υπογραφής ή αποδεικτικά παρόχων υπηρεσιών\.

Οι προτάσεις νέων δυνατοτήτων θα πρέπει να περιγράφουν το αποτέλεσμα για τον χρήστη\, το όριο ασφαλείας και μια στρατηγική επικύρωσης\.

Για πιθανές ευπάθειες πρέπει να ακολουθείται η ιδιωτική διαδικασία στο [SECURITY\.md](security.md) και όχι να ανοίγεται δημόσιο αίτημα υποστήριξης\.
