[Επισκόπηση σε 41 τοπικοποιημένες εκδόσεις και επίσημα σημεία πρόσβασης στον ιστό](../../../docs/LANGUAGES.md)\. Η αγγλική έκδοση αυτού του πλαισίου σύνταξης παραμένει η κανονική πηγή αναφοράς\.

Ένα README του Better Workflows είναι σελίδα υποδοχής\, όχι συμπυκνωμένο εγχειρίδιο αναφοράς\. Ρόλος του είναι να βοηθά τον αναγνώστη να απαντήσει διαδοχικά σε πέντε ερωτήσεις\:

1. Τι είναι αυτό και είναι κατάλληλο για μένα\;
2. Ποιο πρόβλημα λύνει\;
3. Γιατί να εμπιστευτώ τους ισχυρισμούς του\;
4. Ποια είναι η συντομότερη διαδρομή προς μια πρώτη επιτυχία\;
5. Πού πρέπει να συνεχίσω\;

Αυτό το πλαίσιο καθορίζει το συμβόλαιο αφήγησης\, οπτικής παρουσίασης\, τοπικοποίησης και επικύρωσης για κάθε README του αποθετηρίου\. Η μηχανικώς αναγνώσιμη πηγή είναι το [`readme-quality-v1.json`](../../../plugins/better-workflows/config/readme-quality-v1.json)\.

## Ξεκινήστε από την απόφαση του αναγνώστη

Το GitHub εμφανίζει ένα README πριν από το μεγαλύτερο μέρος του περιεχομένου του αποθετηρίου\. Η πρώτη οθόνη πρέπει επομένως να αποσαφηνίζει την υπόσχεση του προϊόντος\, το επιδιωκόμενο κοινό και μια επόμενη ενέργεια με σαφή όρια\. Δεν πρέπει να ξεκινά με την εσωτερική αρχιτεκτονική\, μια πλήρη αναφορά εντολών ή λεπτομέρειες ανάκαμψης εκδόσεων\.

Γράψτε με βάση όσα θέλουν να κάνουν αυτοί οι αναγνώστες\:

- **Νέος επισκέπτης\:** αποφασίστε γρήγορα εάν το Better Workflows επιλύει ένα σχετικό πρόβλημα\.
- **Νέος χρήστης\:** εγκαταστήστε το plugin και ολοκληρώστε μία επιτυχημένη αυτόματη διαδρομή\.
- **Αξιολογητής\:** κατανοήστε το όριο εξουσιοδότησης και τη fail\-closed συμπεριφορά\.
- **Επιστρέφων χειριστής\:** μεταβείτε απευθείας σε μια απάντηση για ροές εργασίας\, ασφάλεια\, αρχιτεκτονική ή το CLI\.
- **Συνεισφέρων ή μεταφραστής\:** βρείτε το κανονικό contract\, τις εντολές ανάπτυξης\, την υποστήριξη και τη διακυβέρνηση\.

## Χρησιμοποιήστε αφήγηση αιτίας και αποτελέσματος

Τα πέντε README υποδοχής χρησιμοποιούν την ίδια σημασιολογική ακολουθία οκτώ μερών\. Οι επικεφαλίδες μπορούν να είναι φυσικές σε κάθε γλώσσα\, αλλά η διαδρομή του αναγνώστη δεν αλλάζει\.

| Ενότητα | Ερώτηση του αναγνώστη και αφηγηματικός ρόλος |
| --- | --- |
| Υπόσχεση και κοινό | Τι είναι το Better Workflows\, γιατί υπάρχει και σε ποιον απευθύνεται\; |
| Από το πρόβλημα στο αποτέλεσμα | Τι πάει στραβά όταν συγχέονται η πρόθεση\, η αρμοδιότητα\, τα τεκμήρια και το αποτέλεσμα του παρόχου\; |
| Απόδειξη και όρια | Ποιες εγγυήσεις καθιστούν αξιόπιστο το προτεινόμενο αποτέλεσμα\; |
| Πρώτη επιτυχία | Ποια είναι η συντομότερη πλήρης διαδρομή από την εγκατάσταση στο αποτέλεσμα\; |
| Επιλογή επόμενης διαδρομής | Ποια ροή εργασίας ή ποιο έγγραφο ταιριάζει στον στόχο του αναγνώστη\; |
| Κύκλος ζωής | Πώς ένας στόχος οδηγεί σε ολοκλήρωση με επαληθευμένη συμφωνία αποτελεσμάτων — ή σε ασφαλή διακοπή\; |
| Εμπιστοσύνη και περιορισμοί | Τι δεν μπορεί ποτέ το σύστημα να συμπεράνει\, να εξουσιοδοτήσει ή να ισχυριστεί\; |
| Μάθηση\, βοήθεια\, συνεισφορά | Πού βρίσκονται η αναλυτική τεκμηρίωση\, η υποστήριξη\, η διακυβέρνηση\, η ανάπτυξη και η άδεια χρήσης\; |

Αυτή η σειρά δημιουργεί ένα πρακτικό αφηγηματικό τόξο\:

- **Πλαίσιο\:** η εργασία που καθοδηγείται από προτροπές μπορεί να εκφράζει πρόθεση χωρίς να αποδεικνύει αρμοδιότητα ή κατάσταση\.
- **Ένταση\:** οι παρενέργειες μετατρέπουν αυτό το κενό σε κίνδυνο για την παράδοση του αποτελέσματος\.
- **Επίλυση\:** το Better Workflows συνδέει στόχο\, πεδίο εφαρμογής\, τεκμήρια\, ανασκόπηση\, ενέργεια και επαλήθευση συμφωνίας με το αποτέλεσμα του παρόχου\.
- **Απόδειξη\:** οι ρητές εγγυήσεις και τα όρια δείχνουν πώς λειτουργεί η επίλυση\.
- **Ενέργεια\:** ο αναγνώστης φτάνει σε μια πρώτη επιτυχία πριν συναντήσει εκτενείς λεπτομέρειες υλοποίησης\.
- **Συνέχεια\:** οι διαδρομές βάσει ρόλου και αποτελέσματος οδηγούν τον αναγνώστη στο κατάλληλο εκπαιδευτικό βοήθημα\, πρακτικό οδηγό\, επεξήγηση ή αναφορά\.

Χρησιμοποιήστε το README για πληροφορίες σχετικές με την απόφαση\. Κατευθύνετε στις λεπτομέρειες ανάλογα με τον σκοπό\:

- [Ξεκινώντας](getting-started.md) είναι το εκπαιδευτικό βοήθημα για την πρώτη χρήση\.

- [Αναφορά CLI](cli-reference.md) είναι η αναφορά εντολών\.
- Οι τοπικοποιημένες σελίδες `docs/details/*.md` διατηρούν πλήρως τις μεταφρασμένες λεπτομέρειες\.

Μην επαναλαμβάνετε στη σελίδα υποδοχής την ανάκτηση της κρυφής μνήμης\, την κυριότητα κλειδωμάτων\, την πλήρη σημασιολογία μεταφοράς των παρόχων\, τον εξαντλητικό κατάλογο εντολών ή το ιστορικό αλλαγών υλοποίησης\. Ένας συνοπτικός ισχυρισμός ασφάλειας παραμένει στη σελίδα· οι ελέγξιμες λεπτομέρειές του ανήκουν στον κανονικό οδηγό\.

Αυτός ο διαχωρισμός ακολουθεί τη διάκριση του Diátaxis μεταξύ εκπαιδευτικών βοηθημάτων\, πρακτικών οδηγών\, επεξηγήσεων και αναφορών\. Μία σελίδα δεν μπορεί να βελτιστοποιηθεί για όλες τις τέσσερις ανάγκες του αναγνώστη ταυτόχρονα\.

## Δικαιολογήστε τη θέση κάθε οπτικού στοιχείου

Χρησιμοποιήστε οπτικό στοιχείο μόνο όταν κάνει τις σχέσεις\, την ιεραρχία ή τις μεταβάσεις κατάστασης ουσιαστικά ευκολότερες στην κατανόηση από ό\,τι το πεζό κείμενο\.

Οι σελίδες υποδοχής επιτρέπουν δύο οπτικά στοιχεία\:

1. **Αρχιτεκτονική ορίων αρμοδιότητας\:** απαντά ποια επίπεδα διαμορφώνουν την πρόθεση\, τα τρέχοντα γεγονότα\, την αρμοδιότητα των εργαλείων\, τις περιορισμένες επαναλήψεις προσπαθειών και την κατάσταση μόνο για ανάγνωση\.
2. **Κύκλος ζωής από τον στόχο στην ολοκλήρωση\:** απαντά πού ελέγχονται τα τεκμήρια\, πού εξουσιοδοτούνται οι παρενέργειες και πού η άγνωστη κατάσταση σταματά την πρόοδο\.

Κάθε οπτικό στοιχείο πρέπει να περιλαμβάνει\:

- συνοπτικό\, ουσιαστικό εναλλακτικό κείμενο·
- παρακείμενο κειμενικό ισοδύναμο που διατηρεί το συμπέρασμα όταν το οπτικό στοιχείο είναι κρυμμένο ή δεν γίνεται απόδοση του Mermaid·
- πραγματικό κείμενο για τις ουσιώδεις ετικέτες\, όποτε είναι δυνατόν·
- μια σταθερή ερώτηση του αναγνώστη που δικαιολογεί τη διατήρηση του οπτικού στοιχείου ενημερωμένου\.

Μην προσθέτετε διακοσμητικά στιγμιότυπα οθόνης\, εικόνες με υπερβολικό κείμενο ή διάγραμμα που απλώς επαναλαμβάνει μια σύντομη λίστα\. Περιορίστε τους πίνακες επιλογής σε δύο συνοπτικές στήλες ώστε να παραμένουν χρηστικοί σε στενές οθόνες\.

## Διατηρήστε το νόημα μεταξύ γλωσσών

Τα αγγλικά είναι η σημασιολογική αναφορά\, όχι στόχος για τον αριθμό γραμμών\. Τα παραδοσιακά κινεζικά\, τα απλοποιημένα κινεζικά\, τα ιαπωνικά και τα κορεατικά πρέπει να ακούγονται φυσικά σε έναν φυσικό ομιλητή\, διατηρώντας παράλληλα το ίδιο συμβόλαιο\.

Τα ακόλουθα στοιχεία πρέπει να παραμένουν ισοδύναμα\:

- οι οκτώ σημασιολογικές ενότητες και η σειρά τους·
- οι εντολές για την πρώτη επιτυχία και τα αναγνωριστικά προϊόντων·
- οι πέντε ισχυρισμοί για αρμοδιότητα\, τεκμήρια\, άγνωστη κατάσταση\, προτροπές και ιδιωτικότητα·
- οι προορισμοί για ροές εργασίας\, ασφάλεια\, αρχιτεκτονική\, CLI\, υποστήριξη\, διακυβέρνηση\, ανάπτυξη και άδεια χρήσης·
- ο σκοπός των οπτικών στοιχείων\, τα στάδια του κύκλου ζωής και οι κειμενικές εναλλακτικές·
- η πηγή της έκδοσης και η πολιτική σημάτων\.

Οι επικεφαλίδες\, τα όρια προτάσεων\, η στίξη\, τα παραδείγματα και οι προτροπές για ενέργεια μπορούν να είναι φυσικά για κάθε γλώσσα\. Μην μεταφράζετε ποτέ εντολές\, επιλογείς\, αναγνωριστικά τεκμηρίων ή σημασιολογία ασφάλειας\.

## Γράψτε για γρήγορη ανάγνωση και μετάφραση

- Ξεκινήστε με το αποτέλεσμα για τον αναγνώστη και τοποθετήστε τους σημαντικούς όρους στην αρχή των επικεφαλίδων και των παραγράφων\.
- Χρησιμοποιήστε ενεργητική φωνή και κατονομάστε τον υπεύθυνο φορέα μιας ενέργειας\.
- Απευθυνθείτε απευθείας στον αναγνώστη στις διαδικασίες\.
- Κρατήστε τις παραγράφους σύντομες και δώστε σε καθεμία μία μόνο δουλειά\.
- Χρησιμοποιήστε αριθμημένες λίστες για ακολουθίες και κουκκίδες για επιλογές χωρίς σειρά\.
- Χρησιμοποιήστε περιγραφικούς συνδέσμους αντί για γενικές ετικέτες όπως «κάντε κλικ εδώ»\.
- Διατηρήστε τις επικεφαλίδες ιεραρχικές\, συγκεκριμένες και παράλληλες στη διατύπωση στο ίδιο επίπεδο\.
- Προτιμήστε κυριολεκτική\, σαφή γλώσσα που διατηρεί το νόημά της στη μετάφραση\.
- Βάλτε τις προϋποθέσεις πριν από τις οδηγίες και τα αναμενόμενα αποτελέσματα μετά τις εντολές\.

## Επικυρώστε τη σημασιολογία\, όχι τη διακόσμηση

Οι δοκιμές τεκμηρίωσης πρέπει να ανιχνεύουν περισσότερα από την αντιστοιχία επικεφαλίδων\. Επαληθεύουν\:

- ένα H1 και μια λογική ιεραρχία επικεφαλίδων·
- ταξινομημένη σημασιολογική ενότητα και δείκτες κρίσιμων ισχυρισμών·
- ακριβείς εντολές πρώτης επιτυχίας και σταθερά αναγνωριστικά·
- σχετικοί σύνδεσμοι και προορισμοί λεπτομερειών ειδικοί για κάθε γλώσσα·
- ισοτιμία σημάτων έκδοσης με μεταδεδομένα χρόνου εκτέλεσης·
- ουσιαστικό κείμενο alt εικόνας και παρακείμενα οπτικά εφεδρικά στοιχεία·
- ένας μοναδικός κύκλος ζωής Mermaid με πλήρες ισοδύναμο κειμένου·
- όρια μεγέθους για πίνακες δύο στηλών και μήκος παραγράφων·
- απουσία καθορισμένων λεπτομερειών βαθιάς υλοποίησης από τις σελίδες προορισμού·
