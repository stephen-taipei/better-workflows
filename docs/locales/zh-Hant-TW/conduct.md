## 我們的標準

我們致力於建立彼此尊重、技術討論嚴謹且沒有騷擾的社群。

我們期待以下行為：

- 針對證據與取捨進行討論，而不是人身攻擊；
- 提供具體、可採取行動且合乎比例的回饋；
- 承認不確定之處，並公開更正錯誤；
- 尊重隱私、保密要求與負責任的漏洞揭露；
- 歡迎不同背景及經驗的貢獻者。

不可接受的行為包括騷擾、歧視、威脅、肉搜、帶有性意味的不受歡迎關注、蓄意恐嚇，或未經同意公開他人的私人資訊。

## 適用範圍

本準則適用於儲存庫的議題、合併請求、審查、討論，以及代表本專案參與的其他場合。

## 通報與處理

請勿在公開議題中提交含敏感資訊的行為通報。請透過儲存庫擁有者 GitHub 個人檔案所公布的私人聯絡方式聯繫維護者，並提供：

- 事件發生的地點與日期；
- 客觀事實描述；
- 相關連結或截圖；
- 任何迫切的安全或隱私疑慮。

維護者會以保密方式審查通報並避免利益衝突，必要時可編輯或移除內容、提出警告、暫時限制參與或永久禁止參與。明知不實的通報或報復性通報同樣違反本準則。

針對 GitHub 平台上的濫用行為或威脅，也可直接透過 [GitHub 支援](https://support.github.com/contact/report-abuse)通報。
