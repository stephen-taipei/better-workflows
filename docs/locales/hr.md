V5.0 RC1 pokriva Codex, Gemini CLI i Qwen Code na sustavu macOS × Node 22/24. Kvalifikacija za Claude Code, Linux i Windows odgođena je za V5.1. GA zahtijeva najmanje 30 prirodnih dana canary testiranja, 20 uzastopnih kvalificiranih pokretanja i tri zasebna repozitorija.

## Dovedite rad agenata<br>do dokazivog završetka.

V5.0 RC1 javno je dostupan. Auto provjerava cilj, opseg, repozitorij i rizik, a zatim odabire ciljane provjere ili tijek rada s dokazima. Git izmjene koriste worktree u vlasništvu zadatka; isporuka zahtijeva autorizaciju i provjereni vanjski ishod.
