# Better Workflows

Better Workflows V5.0 RC1 je verejne dostupné: bezplatný, open-source Auto workflow pre QA a doručenie AI inžinierstva s aktuálnymi dôkazmi, review gates a zosúladením poskytovateľov.

V5.0 RC1 pokrýva Codex, Gemini CLI a Qwen Code na macOS × Node 22/24. Kvalifikácia pre Claude Code, Linux a Windows je odložená na V5.1. GA vyžaduje aspoň 30 prirodzených kanárikových dní, 20 po sebe idúcich spôsobilých spustení a tri rôzne repozitáre.

## Doveďte prácu agentov<br>k preukázateľnému dokončeniu.

V5.0 RC1 je verejne dostupné. Auto skontroluje cieľ, rozsah, repozitár a riziko, a potom vyberie cielené kontroly alebo evidence workflow. Zmeny Git používajú worktree vo vlastníctve úlohy; doručenie vyžaduje autorizáciu a overený externý výsledok.

- **03 · `reconciliation`** — Definujte zmluvu, overte zdroj a dôkazy, zosúlaďte externé účinky a dokončenie vyhláste až vtedy, keď je koncový stav známy.
