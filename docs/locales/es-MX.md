V5.0 RC1 cubre Codex, Gemini CLI y Qwen Code en macOS × Node 22/24. La calificación para Claude Code, Linux y Windows se pospone para V5.1. GA requiere al menos 30 días naturales de canary, 20 inicios elegibles consecutivos y tres repositorios distintos.

## Lleva el trabajo de los agentes<br>hasta un cierre comprobable.

V5.0 RC1 ya está disponible públicamente. Auto verifica el objetivo, el alcance, el repositorio y el riesgo, y luego selecciona comprobaciones dirigidas o un flujo de trabajo de evidencia. Los cambios Git usan un worktree propiedad de la tarea; la entrega requiere autorización y un resultado externo verificado.
