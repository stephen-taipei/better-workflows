V5.0 RC1 dekker Codex, Gemini CLI og Qwen Code på macOS × Node 22/24. Kvalifisering for Claude Code, Linux og Windows er utsatt til V5.1. GA krever minst 30 naturlige canary-dager, 20 påfølgende kvalifiserte oppstarter og tre distinkte depoter.

## Før agentarbeidet<br>helt fram til en etterprøvbar avslutning.

V5.0 RC1 er offentlig tilgjengelig. Auto sjekker mål, omfang, repository og risiko, og velger deretter målrettede kontroller eller en evidensarbeidsflyt. Git-endringer bruker en oppgave-eid worktree; levering krever autorisasjon og et verifisert eksternt resultat.
