La versió V5.0 RC1 cobreix Codex, Gemini CLI i Qwen Code a macOS × Node 22/24. La qualificació de Claude Code, Linux i Windows s'ajorna a la versió V5.1. GA requereix almenys 30 dies naturals de canary, 20 inicis aptes consecutius i tres repositoris diferents.

## Porta la feina dels agents<br>fins a un final demostrable.

V5.0 RC1 està disponible públicament. Auto comprova l’objectiu, l’abast, el repositori i el risc, i després selecciona comprovacions específiques o un flux de treball d’evidència. Els canvis Git fan servir un worktree propietat de la tasca; el lliurament requereix autorització i un resultat extern verificat.

## Quatre límits clars entre la intenció i la finalització.

Defineix el contracte, verifica la font i l’evidència, concilia els efectes externs i només declara la finalització quan l’estat terminal és conegut.

- **01 · `TaskContract`** — V5.0 RC1 està disponible públicament. Els canvis Git fan servir un worktree propietat de la tasca; el lliurament requereix autorització i un resultat extern verificat.
- **02 · `evidence`** — Better Workflows V5.0 RC1 ja està disponible públicament: un flux de treball Auto gratuït i de codi obert per a QA i lliurament d’enginyeria d’IA, amb evidència actual, gates de revisió i conciliació de proveïdors.
- **03 · `reconciliation`** — Defineix el contracte, verifica la font i l’evidència, concilia els efectes externs i només declara la finalització quan l’estat terminal és conegut.
- **04 · `terminal state`** — Executar una ordre no prova que la feina s’hagi acabat; un resultat revalidable sí.
