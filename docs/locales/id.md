## Bawa pekerjaan agent<br>hingga selesai dengan bukti.

V5.0 RC1 telah tersedia untuk umum. Auto memeriksa tujuan, cakupan, repositori, dan risiko, lalu memilih pemeriksaan terarah atau alur kerja bukti. Perubahan Git memakai worktree milik tugas; pengiriman memerlukan otorisasi dan hasil eksternal yang terverifikasi.
