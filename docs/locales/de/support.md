## Um Hilfe bitten

Wenn du eine Frage zur Nutzung hast oder einen reproduzierbaren Fehler melden möchtest\, erstelle auf GitHub eine Meldung mit folgenden Angaben\:

- Version von Better Workflows und Programmstand des Codex\-Plugins\;
- verwendete Codex\-Oberfläche und Node\.js\-Version\;
- verwendeter Befehl oder Eintrag im Auswahlmenü\;
- erwartetes und beobachtetes Verhalten\;
- von sensiblen Daten bereinigte Ausgabe und ein minimales Beispiel zur Reproduktion\.

Füge keine Zugangsdaten\, unbereinigten privaten Eingabetexte\, Materialien zum Signieren oder Belege von Anbietern bei\.

Funktionsvorschläge sollten das Nutzerergebnis\, die Sicherheitsgrenze und eine Validierungsstrategie beschreiben\.

Bei vermuteten Sicherheitslücken muss das vertrauliche Meldeverfahren in [SECURITY\.md](security.md) genutzt werden\; sie dürfen nicht als öffentliche Supportanfrage gemeldet werden\.
