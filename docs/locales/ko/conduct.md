## 우리의 기준

우리는 서로를 존중하고 기술적으로 엄밀하며 괴롭힘이 없는 커뮤니티를 유지하기 위해 노력합니다\.

기대하는 행동은 다음과 같습니다\:

- 사람을 공격하는 대신 증거와 절충점을 논의하기\;
- 구체적이고 실행 가능하며 사안에 비례하는 피드백 제공하기\;
- 불확실성을 인정하고 실수를 공개적으로 바로잡기\;
- 사생활\, 기밀 유지\, 책임 있는 정보 공개를 존중하기\;
- 배경이나 경험과 관계없이 기여자를 환영하기\.

허용되지 않는 행동에는 괴롭힘\, 차별\, 협박\, 신상 털기\, 성적 관심 표출\, 고의적인 위압\, 다른 사람의 사적인 정보를 허락 없이 공개하는 행위가 포함됩니다\.

## 적용 범위

이 기준은 저장소의 이슈\, 풀 리퀘스트\, 리뷰\, 토론 및 누군가가 이 프로젝트를 대표하는 그 밖의 공간에 적용됩니다\.

## 신고 및 집행

민감한 행동 관련 신고를 공개 이슈에 게시하지 마세요\. 저장소 소유자의 GitHub 프로필에 공개된 비공개 연락 수단으로 유지 관리자에게 연락하고 다음 내용을 포함하세요\:

- 사건이 발생한 장소와 날짜\;
- 사실에 근거한 설명\;
- 관련 링크 또는 스크린샷\;
- 즉각적인 안전 또는 사생활 보호 우려 사항\.

유지 관리자는 신고를 기밀로 검토하고 이해충돌을 피하며\, 콘텐츠를 수정하거나 삭제하고\, 경고를 발행하고\, 참여를 일시적으로 제한하거나 영구적으로 금지할 수 있습니다\. 허위임을 알면서 제기하는 신고나 보복성 신고도 이 강령을 위반합니다\.

GitHub 플랫폼 악용이나 협박은 [GitHub 지원](https://support.github.com/contact/report-abuse)을 통해 직접 신고할 수도 있습니다\.
