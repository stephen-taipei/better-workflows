## 도움 요청

사용 방법에 관한 질문이나 재현 가능한 결함은 다음 정보를 포함하여 GitHub 이슈를 등록해 주세요\:

- Better Workflows 버전과 Codex 플러그인 빌드
- 사용 중인 Codex 인터페이스와 Node\.js 버전
- 사용한 명령어 또는 선택 메뉴 항목
- 예상한 동작과 실제로 관찰한 동작
- 민감한 정보를 제거한 출력과 최소 재현 예제\.

인증 정보\, 비공개 프롬프트 원문\, 서명에 사용하는 자료\, 서비스 제공업체의 수령 증빙은 포함하지 마세요\.

기능 제안서에는 사용자 결과\, 안전 경계 및 검증 전략이 기술되어야 합니다\.

취약점이 의심되는 경우 공개 지원 이슈를 등록하지 말고 [SECURITY\.md](security.md)에 명시된 비공개 보고 절차를 반드시 따라야 합니다\.
