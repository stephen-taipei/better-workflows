## အကူအညီတောင်းခံရန်

အသုံးပြုနည်းဆိုင်ရာ မေးခွန်း သို့မဟုတ် ပြန်လည်ဖြစ်ပေါ်စေနိုင်သည့် ချို့ယွင်းချက်အတွက် အောက်ပါအချက်အလက်များနှင့်အတူ GitHub တွင် ပြဿနာတင်ပြချက်တစ်ခု ဖွင့်ပါ\:

- Better Workflows ဗားရှင်းနှင့် Codex ပလပ်အင်၏ တည်ဆောက်ထားသည့် မူကွဲ
- အသုံးပြုနေသည့် Codex မျက်နှာပြင်နှင့် Node\.js ဗားရှင်း
- အသုံးပြုခဲ့သော အမိန့် သို့မဟုတ် ရွေးချယ်မှုမီနူးမှ ရွေးချယ်ခဲ့သည့်အချက်
- မျှော်လင့်ထားသော လုပ်ဆောင်ပုံနှင့် အမှန်တကယ် တွေ့ရှိရသော လုပ်ဆောင်ပုံ
- လျှို့ဝှက်အချက်အလက်များ ဖယ်ရှားထားသော အထွက်ရလဒ်နှင့် ပြဿနာကို ပြန်လည်ဖြစ်ပေါ်စေရန် အနည်းဆုံးလိုအပ်သော နမူနာ။

ဝင်ရောက်အသုံးပြုခွင့် အထောက်အထားများ၊ သီးသန့်ညွှန်ကြားချက်များ၏ မူရင်းစာသားများ၊ လက်မှတ်ရေးထိုးရန် အသုံးပြုသည့် အချက်အလက်နှင့် ပစ္စည်းများ သို့မဟုတ် ဝန်ဆောင်မှုပေးသူ၏ လက်ခံရရှိကြောင်း အထောက်အထားများကို မထည့်သွင်းပါနှင့်။

လုပ်ဆောင်ချက်ဆိုင်ရာ အဆိုပြုချက်များတွင် အသုံးပြုသူရလဒ်၊ လုံခြုံရေးနယ်နိမိတ်နှင့် အတည်ပြုခြင်းဆိုင်ရာ မဟာဗျူဟာတို့ကို ဖော်ပြသင့်သည်။

လုံခြုံရေးအားနည်းချက်ဟု သံသယရှိပါက အများမြင်နိုင်သည့် အကူအညီတောင်းခံချက်အဖြစ် မတင်ပြဘဲ [SECURITY\.md](security.md) တွင် ဖော်ပြထားသော သီးသန့်တင်ပြသည့် လုပ်ငန်းစဉ်ကို မဖြစ်မနေ အသုံးပြုရမည်။
