## ကျွန်ုပ်တို့၏ စံနှုန်း

အပြန်အလှန်လေးစားမှုရှိပြီး နည်းပညာပိုင်းတွင် တိကျခိုင်မာကာ နှောင့်ယှက်စော်ကားမှုကင်းသော အသိုင်းအဝိုင်းဖြစ်ရန် ကျွန်ုပ်တို့ ကတိပြုထားသည်။

မျှော်လင့်ထားသော အပြုအမူများမှာ\:

- လူပုဂ္ဂိုလ်ကို တိုက်ခိုက်မည့်အစား အထောက်အထားနှင့် အကျိုးအပြစ်ချိန်ဆမှုများကို ဆွေးနွေးခြင်း\;
- တိကျ၍ လက်တွေ့ဆောင်ရွက်နိုင်ပြီး ကိစ္စနှင့်အချိုးညီသော အကြံပြုချက်ပေးခြင်း\;
- မသေချာမှုကို ဝန်ခံပြီး အမှားများကို ပွင့်လင်းစွာ ပြင်ဆင်ခြင်း\;
- ကိုယ်ရေးကိုယ်တာလုံခြုံမှု၊ လျှို့ဝှက်ချက်ထိန်းသိမ်းမှုနှင့် တာဝန်ယူမှုရှိသော ထုတ်ဖော်မှုကို လေးစားခြင်း\;
- နောက်ခံ သို့မဟုတ် အတွေ့အကြုံမရွေး ပံ့ပိုးပါဝင်သူများကို ကြိုဆိုခြင်း။

လက်မခံနိုင်သော အပြုအမူများတွင် နှောင့်ယှက်စော်ကားခြင်း၊ ခွဲခြားဆက်ဆံခြင်း၊ ခြိမ်းခြောက်ခြင်း၊ လူတစ်ဦး၏ အထောက်အထားဖော်ထုတ်နိုင်သော အချက်အလက်များကို ခွင့်မပြုဘဲ ဖော်ထုတ်ခြင်း၊ လိင်သဘောဆောင်သော အာရုံစိုက်ပြုမူခြင်း၊ တမင်ကြောက်ရွံ့အောင် ပြုလုပ်ခြင်း သို့မဟုတ် အခြားသူ၏ ကိုယ်ရေးအချက်အလက်များကို ခွင့်မပြုဘဲ ထုတ်ဝေခြင်းတို့ ပါဝင်သည်။

## အကျုံးဝင်မှု

ဤစံနှုန်းသည် ကုဒ်သိုလှောင်ရာရှိ ပြဿနာတင်ပြချက်များ၊ ကုဒ်ပေါင်းစည်းရန် တောင်းဆိုချက်များ၊ ပြန်လည်သုံးသပ်မှုများ၊ ဆွေးနွေးမှုများနှင့် တစ်ဦးဦးက ဤစီမံကိန်းကို ကိုယ်စားပြုနေသော အခြားနေရာများတွင် အကျုံးဝင်သည်။

## တိုင်ကြားခြင်းနှင့် စည်းကမ်းအကောင်အထည်ဖော်ခြင်း

အပြုအမူနှင့်ပတ်သက်သော အထိခိုက်မခံသည့် တိုင်ကြားချက်များကို အများမြင်နိုင်သော ပြဿနာတင်ပြချက်တွင် မတင်ပါနှင့်။ ကုဒ်သိုလှောင်ရာပိုင်ရှင်၏ GitHub ကိုယ်ရေးစာမျက်နှာတွင် ဖော်ပြထားသော သီးသန့်ဆက်သွယ်နည်းဖြင့် စီမံထိန်းသိမ်းသူကို ဆက်သွယ်ပြီး အောက်ပါတို့ကို ထည့်သွင်းပါ\:

- ဖြစ်ရပ်၏ နေရာနှင့် ရက်စွဲ\;
- အဖြစ်မှန်အပေါ် အခြေခံသော ဖော်ပြချက်\;
- သက်ဆိုင်သော လင့်ခ်များ သို့မဟုတ် မျက်နှာပြင်ပုံများ\;
- ဘေးကင်းရေး သို့မဟုတ် ကိုယ်ရေးကိုယ်တာလုံခြုံမှုနှင့်ပတ်သက်သည့် လတ်တလောစိုးရိမ်စရာများ။

စီမံထိန်းသိမ်းသူများသည် တိုင်ကြားချက်များကို လျှို့ဝှက်စွာ စိစစ်ပြီး အကျိုးစီးပွားပဋိပက္ခများကို ရှောင်ရှားမည်။ အကြောင်းအရာကို ပြင်ဆင်ခြင်း သို့မဟုတ် ဖယ်ရှားခြင်း၊ သတိပေးခြင်း၊ ပါဝင်ခွင့်ကို ယာယီကန့်သတ်ခြင်း သို့မဟုတ် အမြဲတမ်းပိတ်ပင်ခြင်းတို့ ပြုလုပ်နိုင်သည်။ မမှန်ကြောင်းသိလျက် တိုင်ကြားခြင်း သို့မဟုတ် လက်တုံ့ပြန်ရန် တိုင်ကြားခြင်းသည်လည်း ဤကျင့်ဝတ်ကို ချိုးဖောက်သည်။

GitHub ပလက်ဖောင်းကို အလွဲသုံးစားပြုမှု သို့မဟုတ် ခြိမ်းခြောက်မှုများကို [GitHub အကူအညီဌာန](https://support.github.com/contact/report-abuse) မှတစ်ဆင့်လည်း တိုက်ရိုက်တိုင်ကြားနိုင်သည်။
