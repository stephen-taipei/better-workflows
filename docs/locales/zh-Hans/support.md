## 寻求帮助

如有使用问题或可复现的错误，请在 GitHub 创建议题，并提供：

- Better Workflows 版本和 Codex 插件的构建版本；
- 使用的 Codex 界面和 Node\.js 版本；
- 执行的命令或选择器选项；
- 预期与实际观察到的行为；
- 已移除敏感信息的输出和最小复现步骤。

请勿附上凭据、未经处理的私人提示内容、签名所需材料或服务提供商回执。

功能提案应说明用户产出、安全边界以及验证策略。

如怀疑发现安全漏洞，必须按照 [SECURITY\.md](security.md) 的非公开报告流程处理，不可在公开的支持议题中提出。
