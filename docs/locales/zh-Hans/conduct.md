## 我们的标准

我们致力于建立相互尊重、技术讨论严谨且没有骚扰的社区。

我们期待以下行为：

- 围绕证据与取舍展开讨论，而不是人身攻击；
- 提供具体、可付诸行动且适度的反馈；
- 承认不确定之处，并公开纠正错误；
- 尊重隐私、保密要求与负责任的漏洞披露；
- 欢迎不同背景及经验的贡献者。

不可接受的行为包括骚扰、歧视、威胁、人肉搜索、带有性意味的不受欢迎的关注、蓄意恐吓，或未经同意公开他人的私人信息。

## 适用范围

本准则适用于仓库中的议题、拉取请求、评审、讨论，以及代表本项目参与的其他场合。

## 举报与处理

请勿在公开议题中提交含敏感信息的行为举报。请通过仓库所有者 GitHub 个人资料中公布的私密联系方式联系维护者，并提供：

- 事件发生的地点与日期；
- 客观事实描述；
- 相关链接或截图；
- 任何紧迫的安全或隐私风险。

维护者会以保密方式审核举报并避免利益冲突，必要时可编辑或删除内容、发出警告、暂时限制参与或永久禁止参与。明知不实的举报或报复性举报同样违反本准则。

对于 GitHub 平台上的滥用行为或威胁，也可直接通过 [GitHub 支持](https://support.github.com/contact/report-abuse)举报。
