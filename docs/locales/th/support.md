## ขอความช่วยเหลือ

หากมีคำถามเกี่ยวกับการใช้งานหรือพบข้อบกพร่องที่ทำให้เกิดซ้ำได้ ให้เปิดประเด็นใน GitHub พร้อมข้อมูลต่อไปนี้\:

- เวอร์ชัน Better Workflows และบิลด์ของปลั๊กอิน Codex
- ส่วนติดต่อ Codex ที่ใช้งานและเวอร์ชัน Node\.js
- คำสั่งหรือรายการในเมนูตัวเลือกที่ใช้
- พฤติกรรมที่คาดหวังและพฤติกรรมที่พบจริง
- ผลลัพธ์ที่ลบข้อมูลอ่อนไหวออกแล้ว และตัวอย่างขนาดเล็กที่สุดที่ทำให้เกิดปัญหาซ้ำได้

ห้ามใส่ข้อมูลรับรองการเข้าถึง ข้อความพรอมป์ต์ส่วนตัวฉบับดิบ ข้อมูลหรือสิ่งที่ใช้ในการลงนาม หรือหลักฐานการรับจากผู้ให้บริการ

ข้อเสนอคุณลักษณะควรระบุผลลัพธ์ของผู้ใช้\, ขอบเขตความปลอดภัย และกลยุทธ์การตรวจสอบความถูกต้อง

หากสงสัยว่ามีช่องโหว่ ต้องใช้กระบวนการรายงานแบบส่วนตัวใน [SECURITY\.md](security.md) แทนการเปิดประเด็นขอความช่วยเหลือแบบสาธารณะ
