## มาตรฐานของเรา

เรามุ่งมั่นสร้างชุมชนที่เคารพซึ่งกันและกัน เคร่งครัดในความถูกต้องทางเทคนิค และปราศจากการคุกคาม

พฤติกรรมที่คาดหวัง ได้แก่\:

- อภิปรายหลักฐานและข้อแลกเปลี่ยน แทนการโจมตีตัวบุคคล\;
- ให้ข้อเสนอแนะที่เฉพาะเจาะจง นำไปปฏิบัติได้ และได้สัดส่วนกับประเด็น\;
- ยอมรับความไม่แน่นอนและแก้ไขข้อผิดพลาดอย่างเปิดเผย\;
- เคารพความเป็นส่วนตัว การรักษาความลับ และการเปิดเผยข้อมูลอย่างรับผิดชอบ\;
- ต้อนรับผู้ร่วมพัฒนาโดยไม่แบ่งแยกภูมิหลังหรือประสบการณ์

พฤติกรรมที่ยอมรับไม่ได้ ได้แก่ การคุกคาม การเลือกปฏิบัติ การข่มขู่ การเปิดเผยข้อมูลระบุตัวบุคคลโดยไม่ได้รับอนุญาต การแสดงความสนใจในเชิงเพศ การจงใจทำให้หวาดกลัว หรือการเผยแพร่ข้อมูลส่วนตัวของผู้อื่นโดยไม่ได้รับอนุญาต

## ขอบเขต

มาตรฐานนี้ใช้กับประเด็นปัญหา คำขอรวมโค้ด การทบทวน และการสนทนาในที่เก็บโค้ด รวมถึงพื้นที่อื่นที่มีผู้แสดงตนเป็นตัวแทนของโครงการนี้

## การรายงานและการบังคับใช้

อย่าโพสต์รายงานพฤติกรรมที่มีข้อมูลอ่อนไหวในประเด็นปัญหาสาธารณะ ให้ติดต่อผู้ดูแลโครงการผ่านช่องทางติดต่อส่วนตัวที่เผยแพร่ไว้ในโปรไฟล์ GitHub ของเจ้าของที่เก็บโค้ด และระบุ\:

- สถานที่และวันที่เกิดเหตุ\;
- คำอธิบายตามข้อเท็จจริง\;
- ลิงก์หรือภาพหน้าจอที่เกี่ยวข้อง\;
- ข้อกังวลเร่งด่วนด้านความปลอดภัยหรือความเป็นส่วนตัว

ผู้ดูแลโครงการจะพิจารณารายงานโดยรักษาความลับ หลีกเลี่ยงผลประโยชน์ทับซ้อน และอาจแก้ไขหรือลบเนื้อหา ออกคำเตือน จำกัดการมีส่วนร่วมชั่วคราว หรือห้ามมีส่วนร่วมอย่างถาวร การรายงานทั้งที่รู้ว่าเป็นเท็จหรือเพื่อแก้แค้นก็ถือเป็นการละเมิดจรรยาบรรณนี้เช่นกัน

การใช้แพลตฟอร์ม GitHub ในทางที่ผิดหรือการข่มขู่ยังสามารถรายงานโดยตรงผ่าน [ฝ่ายสนับสนุน GitHub](https://support.github.com/contact/report-abuse) ได้ด้วย
