[ภาพรวมที่ปรับให้เหมาะกับท้องถิ่น 41 ฉบับและช่องทางเข้าสู่เว็บไซต์อย่างเป็นทางการ](../../../docs/LANGUAGES.md) นโยบายการกำกับดูแลฉบับกำหนดข้อบังคับนี้ยังคงยึดฉบับภาษาอังกฤษเป็นหลักอ้างอิงที่มีผลบังคับใช้

Better Workflows ดำเนินงานภายใต้การนำของผู้ดูแลโครงการ

## รูปแบบการตัดสินใจ

- ผู้ดูแลโครงการเป็นผู้ยอมรับหรือปฏิเสธการเปลี่ยนแปลงด้านการออกแบบและการเผยแพร่ในระดับโครงการ
- พิจารณาหลักฐาน การทดสอบที่ทำซ้ำได้ ขอบเขตความปลอดภัย ความเข้ากันได้ และ ต้นทุนการบำรุงรักษาก่อนความนิยม หรือการลงคะแนนเสียงข้างมาก
- การเปลี่ยนแปลงข้อกำหนดสัญญาสาธารณะและขอบเขตความปลอดภัยต้องผ่านการตรวจทานอย่างชัดเจน
- ข้อเสนอที่ถูกปฏิเสธอาจได้รับการพิจารณาใหม่เมื่อหลักฐานใหม่เปลี่ยน ดุลของข้อดีข้อเสีย

## อำนาจในเวิร์กโฟลว์

ภายในการรัน Better Workflows นั้น Root เป็นผู้มีอำนาจแต่เพียงผู้เดียวในการแก้ไขและยอมรับ ความเสี่ยง กฎรันไทม์นี้ไม่ได้มอบความเป็นเจ้าของรีโพซิทอรีหรือ ลบล้างสิทธิ์ของ GitHub

## การเผยแพร่รุ่น

บิลด์ของแคชปลั๊กอินไม่สามารถแก้ไขเปลี่ยนแปลงได้ รุ่นเตรียมเผยแพร่ต้องผ่านด่านที่เกี่ยวข้องทั้งหมดก่อนเผยแพร่ ได้แก่ การทดสอบ การประเมิน ความทันเวลาของหลักฐาน การตรวจสอบหลักฐาน สาขาที่มีการป้องกัน และการตรวจสอบความสอดคล้องระหว่างซอร์สกับแคช

## การเปลี่ยนแปลงการกำกับดูแล

การเปลี่ยนแปลงการกำกับดูแลจะได้รับการตรวจทานเช่นเดียวกับการเปลี่ยนแปลงข้อกำหนดสัญญาสาธารณะ และต้องบันทึกไว้ ในประวัติของคลังซอร์สโค้ด
