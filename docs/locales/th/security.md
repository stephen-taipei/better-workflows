## เวอร์ชันที่รองรับ

| เวอร์ชัน | การรองรับ |
| --- | --- |
| รุ่นเผยแพร่ล่าสุดและบิลด์ Codex ที่แก้ไขเปลี่ยนแปลงไม่ได้ | รองรับ |
| เวอร์ชันแคชที่แก้ไขเปลี่ยนแปลงไม่ได้รุ่นเก่า | ใช้เป็นเป้าหมายสำหรับย้อนกลับรุ่น โดยจะไม่นำการแก้ไขไปใช้ย้อนหลังกับรุ่นเก่า เว้นแต่จะประกาศไว้อย่างชัดเจน |
| รุ่นแยกพัฒนาที่ยังไม่เผยแพร่หรือเนื้อหาแคชที่ถูกแก้ไข | ไม่รองรับ |

## รายงานช่องโหว่

โปรดใช้ [การรายงานช่องโหว่แบบส่วนตัวของ GitHub](https://github.com/stephen-taipei/better-workflows/security/advisories/new) ห้ามเปิดประเด็นสาธารณะสำหรับช่องโหว่ที่สงสัย

ระบุข้อมูลต่อไปนี้\:

- เวอร์ชันและบิลด์ปลั๊กอินที่ได้รับผลกระทบ\;
- สภาพแวดล้อมและเวอร์ชัน Node\.js\;
- ขั้นตอนขั้นต่ำในการทำให้เกิดปัญหาซ้ำ\;
- ขอบเขตความปลอดภัยที่คาดหวังและที่สังเกตพบ\;
- ผลกระทบและวิธีแก้ขัดที่ทราบ\;
- รายงานมีข้อมูลลับหรือไม่

ห้ามใส่ข้อมูลรับรองที่ยังใช้งานได้ กุญแจลงนาม โทเค็นของผู้ให้บริการ พรอมป์ต์ส่วนตัว ฉบับดิบ หรือข้อมูลส่วนบุคคลของบุคคลที่สาม

## การตอบกลับ

ผู้ดูแลโครงการจะยืนยันการรับรายงานที่มีข้อมูลเพียงพอต่อการดำเนินการ ตรวจสอบขอบเขต และ ประสานการแก้ไขกับการเปิดเผยข้อมูล โดยไม่รับประกัน SLA ที่กำหนดเวลาตอบกลับตายตัว ผลลัพธ์ที่ยังไม่ทราบหรือยังไม่ได้ตรวจสอบเทียบให้สอดคล้องกันจะยังคงถูกระงับ โดยปฏิเสธการดำเนินการเมื่อยังไม่ได้รับการยืนยัน

## ขอบเขตความปลอดภัย

Better Workflows ตั้งอยู่บนสมมติฐานว่าคลังซอร์สโค้ดภายในเครื่อง เครื่องที่ใช้รัน และชุดเครื่องมือที่เรียกใช้งานได้ เป็นสิ่งที่เชื่อถือได้ โมเดลสิทธิ์ของ Node เป็นการป้องกันเสริมหลายชั้น และไม่ใช่แซนด์บ็อกซ์ระดับระบบปฏิบัติการ สำหรับโค้ดที่เป็นอันตราย ดู [คู่มือความปลอดภัย](security-guide.md) ฉบับสมบูรณ์
