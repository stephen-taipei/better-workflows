## Звернення по допомогу

Якщо маєте запитання щодо використання або помилку\, яку можна відтворити\, створіть звернення на GitHub і вкажіть\:

- версію Better Workflows і збірку плагіна Codex\;
- використаний інтерфейс Codex і версію Node\.js\;
- команду або пункт меню вибору\;
- очікувану та фактичну поведінку\;
- вивід без конфіденційних даних і мінімальні кроки для відтворення\.

Не додавайте облікові дані\, необроблені приватні запити\, матеріали для підписування або квитанції постачальників послуг\.

Пропозиції щодо функцій мають описувати результат для користувача\, межу безпеки та стратегію валідації\.

Про ймовірні вразливості слід повідомляти за приватною процедурою в [SECURITY\.md](security.md)\, а не у відкритому зверненні до підтримки\.
