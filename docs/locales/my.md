## agent အလုပ်ကို<br>သက်သေပြနိုင်သည့် အဆုံးသတ်အထိ ယူဆောင်ပါ။

Better Workflows သည် ရည်မှန်းချက်၊ လုပ်ငန်းအတိုင်းအတာနှင့် လုပ်ပိုင်ခွင့်ကို သတ်မှတ်ပြီး ဆုံးဖြတ်ချက်တိုင်းကို လက်ရှိရင်းမြစ်နှင့် ကိုက်ညီကာ သက်တမ်းရှိဆဲဖြစ်ပြီး ပြန်လည်စစ်ဆေးနိုင်သော အထောက်အထားနှင့် တိုက်ဆိုင်စစ်ဆေးထားသော ပြင်ပရလဒ်တို့နှင့် ချိတ်ဆက်သည်။

## ရည်ရွယ်ချက်မှ ပြီးစီးမှုအထိ ရှင်းလင်းသော နယ်နိမိတ်လေးခု။

စာချုပ်ကို သတ်မှတ်ပြီး ရင်းမြစ်နှင့် အထောက်အထားကို စစ်ဆေးပါ။ ပြင်ပသက်ရောက်မှုများကို တိုက်ဆိုင်စစ်ဆေးပြီး နောက်ဆုံးအခြေအနေကို သိရှိမှသာ ပြီးစီးကြောင်း ကြေညာပါ။

- **01 · `TaskContract`** — Better Workflows သည် ရည်မှန်းချက်၊ လုပ်ငန်းအတိုင်းအတာနှင့် လုပ်ပိုင်ခွင့်ကို သတ်မှတ်ပြီး ဆုံးဖြတ်ချက်တိုင်းကို လက်ရှိရင်းမြစ်နှင့် ကိုက်ညီကာ သက်တမ်းရှိဆဲဖြစ်ပြီး ပြန်လည်စစ်ဆေးနိုင်သော အထောက်အထားနှင့် တိုက်ဆိုင်စစ်ဆေးထားသော ပြင်ပရလဒ်တို့နှင့် ချိတ်ဆက်သည်။
- **02 · `evidence`** — လက်ရှိရင်းမြစ်နှင့် ကိုက်ညီပြီး သက်တမ်းရှိဆဲ အထောက်အထား၊ ပြန်လည်သုံးသပ်ရေးအဆင့်များနှင့် provider အခြေအနေတိုက်ဆိုင်စစ်ဆေးမှု ပါသော အများသုံးမူရင်းကုဒ်၊ ရည်မှန်းချက်ဦးစားပေး agent လုပ်ငန်းစဉ် ထိန်းချုပ်မှုအလွှာ။
- **03 · `reconciliation`** — စာချုပ်ကို သတ်မှတ်ပြီး ရင်းမြစ်နှင့် အထောက်အထားကို စစ်ဆေးပါ။ ပြင်ပသက်ရောက်မှုများကို တိုက်ဆိုင်စစ်ဆေးပြီး နောက်ဆုံးအခြေအနေကို သိရှိမှသာ ပြီးစီးကြောင်း ကြေညာပါ။
- **04 · `terminal state`** — အမိန့်တစ်ခုကို လုပ်ဆောင်ခြင်းသည် ပြီးစီးကြောင်း သက်သေမဟုတ်ပါ; ပြန်လည်စစ်ဆေးနိုင်သော ရလဒ်ကသာ သက်သေဖြစ်သည်။
