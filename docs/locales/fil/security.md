Kung ang tanging iminungkahing pinagmumulan ng ebidensiya ay naglalaman ng pribadong kasaysayan o sensitibong materyal sa operasyon na hindi maaaring alisin o takpan ang sensitibong impormasyon\, huwag itong kolektahin o ipadala\. Itala lamang ang paliwanag na `REJECTED_WITH_EVIDENCE` na inalisan o tinakpan na ng sensitibong impormasyon\.

## Mga sinusuportahang bersiyon

| Bersiyon | Suporta |
| --- | --- |
| Pinakabagong inilathalang bersiyon at hindi nababagong build ng Codex | Sinusuportahan |
| Mas lumang hindi nababagong bersiyon ng cache | Mga bersiyong maaaring balikan\; hindi inilalapat sa mga lumang bersiyon ang mga pag\-aayos maliban kung tahasang ipinahayag |
| Mga hiwalay na kopyang pangkaunlaran na hindi pa inilalabas o binagong nilalaman ng cache | Hindi sinusuportahan |

## Mag\-ulat ng kahinaan sa seguridad

Gamitin ang [pribadong pag\-uulat ng kahinaan sa seguridad sa GitHub](https://github.com/stephen-taipei/better-workflows/security/advisories/new)\. Huwag magbukas ng pampublikong usapin para sa pinaghihinalaang kahinaan sa seguridad\.

Isama ang\:

- apektadong bersiyon at build ng plugin\;
- kapaligiran at bersiyon ng Node\.js\;
- pinakamababang kinakailangang mga hakbang upang maulit ang problema\;
- inaasahan at naobserbahang hangganan ng seguridad\;
- epekto at anumang alam na pansamantalang paraan upang malampasan ang problema\;
- pahayag kung may kumpidensiyal na materyal ang ulat\.

Huwag isama ang aktibong mga kredensiyal\, susi sa paglagda\, token ng tagapagbigay\, hindi naprosesong pribadong mga prompt\, o personal na datos ng ikatlong partido\.

## Tugon

Kikilalanin ng tagapangasiwa ang pagtanggap sa ulat na sapat upang magamit\, patutunayan ang saklaw nito\, at pag\-uugnayin ang pag\-aayos at pagsisiwalat\. Walang ipinapangakong SLA na may takdang tagal ng pagtugon\. Mananatiling nakaharang ang mga kinalabasang hindi pa alam o hindi pa napagtutugma\, at tatanggihan ang pagpapatuloy habang hindi pa napatutunayan\.

## Mga hangganan ng seguridad

Ipinapalagay ng Better Workflows na mapagkakatiwalaan ang lokal na repositoryo\, makinang nagpapatakbo\, at hanay ng mga kasangkapang naipapatakbo\. Ang Modelo ng mga Pahintulot ng Node ay dagdag na patong ng depensa at hindi isang nakahiwalay na kapaligiran ng sistemang pampatakbo para sa mapaminsalang kodigo\. Tingnan ang buong [gabay sa seguridad](security-guide.md)\.
