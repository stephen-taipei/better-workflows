Wersja V5.0 RC1 obejmuje Codex, Gemini CLI i Qwen Code w środowisku macOS × Node 22/24. Kwalifikacja Claude Code, Linux i Windows została odroczona do wersji V5.1. GA wymaga co najmniej 30 naturalnych dni canary, 20 kolejnych kwalifikujących się uruchomień i trzech odrębnych repozytoriów.

## Doprowadź pracę agentów<br>do weryfikowalnego zakończenia.

Wersja V5.0 RC1 jest publicznie dostępna. Auto sprawdza cel, zakres, repozytorium oraz ryzyko, a następnie wybiera ukierunkowane testy lub przepływ pracy oparty na dowodach. Zmiany Git korzystają z worktree należącego do zadania; dostarczenie wymaga autoryzacji i zweryfikowanego rezultatu zewnętrznego.
