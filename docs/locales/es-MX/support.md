## Solicitar ayuda

Si tienes una pregunta sobre el uso o un error reproducible\, abre un reporte en GitHub e incluye\:

- versión de Better Workflows y compilación del complemento de Codex\;
- interfaz de Codex y versión de Node\.js\;
- comando u opción del selector que utilizaste\;
- comportamiento esperado y observado\;
- salida depurada de datos sensibles y un ejemplo mínimo que permita reproducir el problema\.

No incluyas credenciales\, instrucciones privadas sin depurar\, material de firma ni comprobantes de los proveedores\.

Las propuestas de funciones deben describir el resultado para el usuario\, el límite de seguridad y una estrategia de validación\.

Si sospechas de una vulnerabilidad\, debes reportarla mediante el proceso privado indicado en [SECURITY\.md](security.md)\, no en un reporte público de soporte\.
