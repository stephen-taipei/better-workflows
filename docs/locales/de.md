V5.0 RC1 deckt Codex, Gemini CLI und Qwen Code unter macOS × Node 22/24 ab. Die Qualifizierung für Claude Code, Linux und Windows ist auf V5.1 verschoben. GA erfordert mindestens 30 Canary-Kalendertage, 20 aufeinanderfolgende berechtigte Starts und drei verschiedene Repositories.

## Agent-Arbeit bis<br>zum nachweisbaren Abschluss führen.

V5.0 RC1 ist öffentlich verfügbar. Auto prüft Ziel, Umfang, Repository sowie Risiko und wählt dann gezielte Prüfungen oder einen Evidence-Workflow. Git-Änderungen nutzen einen aufgabeneigenen Worktree; die Auslieferung erfordert eine Autorisierung und ein verifiziertes externes Ergebnis.
