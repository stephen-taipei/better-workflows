## ຂໍຄວາມຊ່ວຍເຫຼືອ

ສຳລັບຄຳຖາມກ່ຽວກັບການໃຊ້ງານ ຫຼືຂໍ້ບົກພ່ອງທີ່ສາມາດເຮັດໃຫ້ເກີດຊ້ຳໄດ້ ໃຫ້ເປີດປະເດັນໃນ GitHub ພ້ອມຂໍ້ມູນຕໍ່ໄປນີ້\:

- ເວີຊັນ Better Workflows ແລະຮຸ່ນທີ່ສ້າງຂອງສ່ວນເສີມ Codex
- ສ່ວນຕິດຕໍ່ Codex ທີ່ໃຊ້ງານ ແລະເວີຊັນ Node\.js
- ຄຳສັ່ງ ຫຼືລາຍການໃນເມນູເລືອກທີ່ໃຊ້
- ພຶດຕິກຳທີ່ຄາດຫວັງ ແລະທີ່ພົບເຫັນຈິງ
- ຜົນລັບທີ່ລຶບຂໍ້ມູນອ່ອນໄຫວອອກແລ້ວ ແລະຕົວຢ່າງຂັ້ນຕ່ຳທີ່ໃຊ້ເຮັດໃຫ້ບັນຫາເກີດຊ້ຳໄດ້\.

ຫ້າມໃສ່ຂໍ້ມູນສຳລັບຢືນຢັນສິດເຂົ້າໃຊ້\, ຂໍ້ຄວາມຕົ້ນສະບັບຂອງຄຳສັ່ງສ່ວນຕົວ\, ຂໍ້ມູນຫຼືສິ່ງທີ່ໃຊ້ໃນການລົງນາມ\, ຫຼືຫຼັກຖານການຮັບຈາກຜູ້ໃຫ້ບໍລິການ\.

ຂໍ້ສະເໜີຟີເຈີຄວນອະທິບາຍເຖິງຜົນໄດ້ຮັບຂອງຜູ້ໃຊ້\, ຂອບເຂດຄວາມປອດໄພ\, ແລະຍຸດທະສາດການກວດສອບ\.

ຫາກສົງໄສວ່າມີຊ່ອງໂຫວ່ ຕ້ອງໃຊ້ຂັ້ນຕອນການລາຍງານແບບສ່ວນຕົວໃນ [SECURITY\.md](security.md) ແທນການເປີດປະເດັນຂໍຄວາມຊ່ວຍເຫຼືອແບບສາທາລະນະ\.
