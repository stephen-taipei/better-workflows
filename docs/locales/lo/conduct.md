## ມາດຕະຖານຂອງພວກເຮົາ

ພວກເຮົາມຸ່ງໝັ້ນສ້າງຊຸມຊົນທີ່ເຄົາລົບກັນ\, ຮອບຄອບເຂັ້ມງວດດ້ານເຕັກນິກ ແລະ ປາສະຈາກການຄຸກຄາມ\.

ພຶດຕິກຳທີ່ຄາດຫວັງລວມມີ\:

- ສົນທະນາເລື່ອງຫຼັກຖານ ແລະ ຂໍ້ດີແລະຂໍ້ເສຍຂອງແຕ່ລະທາງເລືອກ ແທນການໂຈມຕີຕົວບຸກຄົນ\;
- ໃຫ້ຄຳຕິຊົມທີ່ສະເພາະເຈາະຈົງ\, ນຳໄປປະຕິບັດໄດ້ ແລະ ໄດ້ສັດສ່ວນກັບປະເດັນ\;
- ຍອມຮັບຄວາມບໍ່ແນ່ນອນ ແລະ ແກ້ໄຂຂໍ້ຜິດພາດຢ່າງເປີດເຜີຍ\;
- ເຄົາລົບຄວາມເປັນສ່ວນຕົວ\, ການຮັກສາຄວາມລັບ ແລະ ການເປີດເຜີຍຢ່າງຮັບຜິດຊອບ\;
- ຕ້ອນຮັບຜູ້ຮ່ວມພັດທະນາໂດຍບໍ່ແບ່ງແຍກພື້ນເພ ຫຼື ປະສົບການ\.

ພຶດຕິກຳທີ່ຍອມຮັບບໍ່ໄດ້ລວມມີ ການຄຸກຄາມ\, ການຈຳແນກປະຕິບັດ\, ການຂົ່ມຂູ່\, ການເປີດເຜີຍຂໍ້ມູນລະບຸຕົວບຸກຄົນໂດຍບໍ່ໄດ້ຮັບອະນຸຍາດ\, ການສະແດງຄວາມສົນໃຈໃນທາງເພດ\, ການຈົງໃຈເຮັດໃຫ້ຢ້ານກົວ ຫຼື ການເຜີຍແຜ່ຂໍ້ມູນສ່ວນຕົວຂອງຜູ້ອື່ນໂດຍບໍ່ໄດ້ຮັບອະນຸຍາດ\.

## ຂອບເຂດ

ມາດຕະຖານນີ້ໃຊ້ກັບລາຍການບັນຫາ\, ຄຳຂໍລວມລະຫັດ\, ການທົບທວນ ແລະ ການສົນທະນາໃນຄັງລະຫັດ ລວມທັງພື້ນທີ່ອື່ນທີ່ມີຜູ້ເປັນຕົວແທນຂອງໂຄງການນີ້\.

## ການລາຍງານ ແລະ ການບັງຄັບໃຊ້

ຢ່າໂພສລາຍງານພຶດຕິກຳທີ່ມີຂໍ້ມູນອ່ອນໄຫວໃນລາຍການບັນຫາສາທາລະນະ\. ຕິດຕໍ່ຜູ້ດູແລໂຄງການຜ່ານວິທີຕິດຕໍ່ສ່ວນຕົວທີ່ເຜີຍແຜ່ໄວ້ໃນໂປຣໄຟລ໌ GitHub ຂອງເຈົ້າຂອງຄັງລະຫັດ ແລະ ລະບຸ\:

- ສະຖານທີ່ ແລະ ວັນທີເກີດເຫດ\;
- ຄຳອະທິບາຍຕາມຂໍ້ເທັດຈິງ\;
- ລິ້ງ ຫຼື ພາບໜ້າຈໍທີ່ກ່ຽວຂ້ອງ\;
- ຂໍ້ກັງວົນເລັ່ງດ່ວນດ້ານຄວາມປອດໄພ ຫຼື ຄວາມເປັນສ່ວນຕົວ\.

ຜູ້ດູແລໂຄງການຈະທົບທວນລາຍງານເປັນຄວາມລັບ\, ຫຼີກລ່ຽງຜົນປະໂຫຍດຂັດກັນ ແລະ ອາດແກ້ໄຂ ຫຼື ລຶບເນື້ອຫາ\, ອອກຄຳເຕືອນ\, ຈຳກັດການມີສ່ວນຮ່ວມຊົ່ວຄາວ ຫຼື ຫ້າມມີສ່ວນຮ່ວມຢ່າງຖາວອນ\. ການລາຍງານທັງທີ່ຮູ້ວ່າເປັນເທັດ ຫຼື ເພື່ອແກ້ແຄ້ນກໍລະເມີດຈັນຍາບັນນີ້ເຊັ່ນກັນ\.

ການໃຊ້ແພລດຟອມ GitHub ໃນທາງທີ່ຜິດ ຫຼື ການຂົ່ມຂູ່ ຍັງສາມາດລາຍງານໂດຍກົງຜ່ານ [ຝ່າຍຊ່ວຍເຫຼືອ GitHub](https://support.github.com/contact/report-abuse) ໄດ້\.
