## Demaneu ajuda

Per a una pregunta d\'ús o un error reproduïble\, obriu una incidència a GitHub i indiqueu\:

- la versió de Better Workflows i la compilació del connector de Codex\;
- la interfície de Codex utilitzada i la versió de Node\.js\;
- l\'ordre o l\'element del selector utilitzat\;
- el comportament esperat i l\'observat\;
- la sortida sense dades sensibles i els passos mínims per reproduir el problema\.

No hi inclogueu credencials\, instruccions privades sense tractar\, material de signatura ni comprovants dels proveïdors de serveis\.

Les propostes de funcionalitats han de descriure el resultat per a l’usuari\, el límit de seguretat i una estratègia de validació\.

Les possibles vulnerabilitats s\'han de comunicar mitjançant el procediment privat de [SECURITY\.md](security.md)\, no amb una incidència pública de suport\.
