V5.0 RC1 cubre Codex, Gemini CLI y Qwen Code en macOS × Node 22/24. La calificación de Claude Code, Linux y Windows se pospone a V5.1. GA requiere al menos 30 días naturales de canary, 20 inicios válidos consecutivos y tres repositorios distintos.

## Lleva el trabajo de los agentes<br>hasta un final demostrable.

V5.0 RC1 está disponible públicamente. Auto comprueba el objetivo, el alcance, el repositorio y el riesgo, y luego selecciona comprobaciones dirigidas o un flujo de trabajo con evidencia. Los cambios Git usan un worktree propio de la tarea; la entrega requiere autorización y un resultado externo verificado.
