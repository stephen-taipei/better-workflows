## 質問・相談

使い方に関する質問や再現可能な不具合については、次の情報を添えて GitHub でイシューを作成してください：

- Better Workflows のバージョンと Codex プラグインのビルド
- 使用している Codex のインターフェースと Node\.js のバージョン
- 使用したコマンド、または選択メニューの項目
- 期待した動作と実際に確認した動作
- 機密情報を除去した出力と、最小限の再現例。

認証情報、非公開プロンプトの原文、署名に使う情報、サービス提供元の受領記録は含めないでください。

機能提案には、ユーザーにとっての成果、安全性境界、および検証戦略を記載する必要があります。

脆弱性が疑われる場合は、公開のサポートイシューを作成せず、[SECURITY\.md](security.md) に記載された非公開の報告手順を必ず利用してください。
