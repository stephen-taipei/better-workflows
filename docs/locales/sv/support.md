## Be om hjälp

Om du har en fråga om användningen eller vill rapportera ett fel som går att återskapa\, skapa ett ärende på GitHub med\:

- version av Better Workflows och kompilerad version av Codex\-tillägget\;
- Codex\-gränssnitt och Node\.js\-version\;
- kommandot eller alternativet i valmenyn som användes\;
- förväntat och observerat beteende\;
- utdata rensade från känsliga uppgifter och ett minimalt exempel som återskapar problemet\.

Ta inte med åtkomstuppgifter\, oredigerade privata instruktioner\, signeringsmaterial eller kvitton från leverantörer\.

Funktionsförslag bör beskriva användarutfallet\, säkerhetsgränsen och en valideringsstrategi\.

Misstänkta sårbarheter måste rapporteras via den privata processen i [SECURITY\.md](security.md)\, inte som ett offentligt supportärende\.
