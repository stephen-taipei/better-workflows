V5.0 RC1 pokrývá Codex, Gemini CLI a Qwen Code na macOS × Node 22/24. Kvalifikace pro Claude Code, Linux a Windows je odložena na V5.1. GA vyžaduje alespoň 30 kalendářních kanárkových dní, 20 po sobě jdoucích způsobilých spuštění a tři různé repozitáře.

## Doveďte práci agentů<br>k prokazatelnému dokončení.

V5.0 RC1 je veřejně k dispozici. Auto zkontroluje cíl, rozsah, repozitář i riziko a poté vybere cílené kontroly nebo evidence workflow. Změny Git používají worktree vlastněný úkolem; doručení vyžaduje autorizaci a ověřený externí výsledek.

## Čtyři jasné hranice mezi záměrem a dokončením.

Definujte smlouvu, ověřte zdroj a důkazy, vyrovnejte externí dopady a dokončení potvrďte teprve tehdy, když je koncový stav známý.

- **01 · `TaskContract`** — V5.0 RC1 je veřejně k dispozici. Auto zkontroluje cíl, rozsah, repozitář i riziko a poté vybere cílené kontroly nebo evidence workflow. Změny Git používají worktree vlastněný úkolem; doručení vyžaduje autorizaci a ověřený externí výsledek.
- **02 · `evidence`** — Better Workflows V5.0 RC1 je veřejně k dispozici: bezplatné open-source workflow Auto pro QA a doručení v AI engineeringu s aktuálními důkazy, review gates a odsouhlasením poskytovatelů.
- **03 · `reconciliation`** — Definujte smlouvu, ověřte zdroj a důkazy, vyrovnejte externí dopady a dokončení potvrďte teprve tehdy, když je koncový stav známý.
- **04 · `terminal state`** — Spuštěný příkaz není důkaz dokončení; znovu ověřitelný výsledek ano.
