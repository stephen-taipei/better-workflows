## 尋求協助

如有使用問題或可重現的錯誤，請在 GitHub 提出議題，並提供：

- Better Workflows 版本及 Codex 外掛的建置版本；
- 使用的 Codex 介面及 Node\.js 版本；
- 執行的指令或選擇器項目；
- 預期與實際觀察到的行為；
- 已移除敏感資料的輸出及最小重現步驟。

請勿附上認證資料、未經處理的非公開提示詞原文、簽章所需資料或服務供應商回執。

功能提案應說明使用者成果、安全邊界以及驗證策略。

如懷疑發現安全漏洞，必須依照 [SECURITY\.md](security.md) 的非公開通報流程處理，不可在公開的支援議題中提出。
