## Duceți munca agenților<br>până la un final demonstrabil.

V5.0 RC1 este disponibil public. Auto verifică obiectivul, domeniul, depozitul și riscul, apoi selectează verificări specifice sau un flux de lucru bazat pe dovezi. Modificările Git folosesc un worktree dedicat sarcinii; livrarea necesită autorizare și un rezultat extern verificat.
