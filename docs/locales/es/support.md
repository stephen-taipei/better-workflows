## Pedir ayuda

Si tienes una duda sobre el uso o un fallo reproducible\, abre una incidencia en GitHub que incluya\:

- versión de Better Workflows y compilación del complemento de Codex\;
- interfaz de Codex y versión de Node\.js\;
- comando u opción del selector que has utilizado\;
- comportamiento esperado y observado\;
- salida sin datos sensibles y un ejemplo mínimo para reproducir el problema\.

No incluyas credenciales\, instrucciones privadas sin depurar\, material de firma ni comprobantes de los proveedores\.

Las propuestas de funciones deben describir el resultado para el usuario\, el límite de seguridad y una estrategia de validación\.

Las posibles vulnerabilidades deben notificarse mediante el procedimiento privado descrito en [SECURITY\.md](security.md)\, no a través de una incidencia pública de soporte\.
