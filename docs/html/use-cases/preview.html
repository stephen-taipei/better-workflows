01

先問後果，再選路線。

route 是工作種類，mode 是驗證強度。兩者分開選，才不會把小修做成儀式，也不會把高風險交付當一般編輯。

一句話：先找最接近的情境；一旦涉及外部副作用、跨平台契約或 release，就提高驗證強度。

02

證據不是狀態，PASS 也不是終點。

evidence 是「發生了什麼」的可驗證紀錄；state 是引擎根據證據做出的持久化決策。Replay 重新評估既有證據，不重做外部副作用。

03

Replay：重播判斷，不重播副作用。

互動示意會沿著既有 run record 重建 route、讀取 evidence、再次評估 stage，最後產生 replay report；它不重新 push、merge、deploy 或發訊息。
