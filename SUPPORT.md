## Ask for help

For a usage question or reproducible defect, open a GitHub issue with:

- the Better Workflows commit you installed and the host (Claude Code version);
- Node.js version and operating system;
- the command or hook involved, and the output of `bw status`;
- expected and observed behavior;
- sanitized output and minimal reproduction.

Do not include credentials, raw private prompts, signing material, or provider
receipts.

Feature proposals should describe the user outcome, the safety boundary, and a
validation strategy.

Suspected vulnerabilities must use the private process in
[SECURITY.md](SECURITY.md), not a public support issue.
