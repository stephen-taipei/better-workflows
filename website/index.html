THE CONTROL PLANE

把「做完」拆成四個可驗證問題。

執行成功不等於證據有效；證據有效也不等於外部副作用已對帳。Better Workflows 讓每個狀態都有明確的資料來源與終止條件。

01

Define

凍結 goal、scope、acceptance、authority 與風險適配的 route。

TaskContract
02

Verify

用 source sentinel、typed evidence、graph 與 review receipt 綁住當前來源。

Evidence
03

Reconcile

副作用只使用一次性 authority；未知 provider 狀態先查明，不盲目重試。

Provider truth
04

Complete

前後重取 sentinel，重新驗證 acceptance、ledger、review 與遠端結果。

Terminal decision

BOUNDARIES OVER PROMISES

速度可以很快，證據必須即時有效。

這是一套 native-first、evidence-driven 的工作流方法：讓小任務保持輕量，讓高風險操作自動提升驗證、審查與 reconciliation 的門檻。

01

Prompt 不是 authority

意圖描述想做什麼，但不會自行授予修改、整合、部署或宣告完成的權力。

02

Evidence before action

每個 side effect 都要有即時、可追溯且綁定目標的 evidence。

03

Unknown 停止，不猜測

drift、stale evidence 與未對帳的 provider outcome 都回到 blocked / indeterminate。
